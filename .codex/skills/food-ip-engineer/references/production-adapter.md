# 生产能力与前台适配专项规则

仅在任务直接涉及前端流程、老板前台、素材 / 上传、时间轴、shot、FFmpeg 或视频导出时读取。

- 前台呈现老板可理解的内容方向、素材和交付结果，不暴露内部 Stage、Agent、Router 或 Memory。
- 修改前端前先检查当前页面流程、项目状态和刷新恢复行为；避免为新主线无关重构、复制业务状态或新增不必要的全局状态。
- 视频相关修改保护 `shot` 编号一致性、素材与上传流程、导出流程，以及 `backend/app/engine/timeline.py` 的时长权威。
- 不在前端或多个模块重复维护最终时长逻辑；复用现有时间轴、素材和 FFmpeg 能力时，先验证其边界和兼容行为。
- 生产适配不应反向改变 Director Core 的产品边界；需要新合约、跨系统状态或迁移时，按主 Skill 的重大决策纪律处理。
